# Sunghyun Sans

Unmodified WOFF2 files from [anaclumos/sunghyun-sans](https://github.com/anaclumos/sunghyun-sans), commit `47224e4e2a3a0c628414e25d8b16f5021207f9d1`.

Licensed under SIL Open Font License 1.1; see `LICENSE`. The main Sans family includes Latin, Cyrillic, Greek, and Vietnamese. CSS in `src/styles.css` registers weights 100–900 with `font-display: swap` and sets Tailwind's default sans family. These are static weight files, not a variable font.
